# CICIDS-2017 Dataset Directory

Place the CICIDS-2017 benchmark CSV files here:
- `Wednesday-workingHours.pcap_ISCX.csv` (DoS / Heartbleed)
- `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv` (DDoS)
- `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv` (PortScan / Recon)

Download source: [UNB CICIDS2017 Dataset](https://www.unb.ca/cic/datasets/ids-2017.html)
